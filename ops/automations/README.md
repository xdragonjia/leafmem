# LeafMem 运维自动化任务模板（随仓库分发）

> 用途：其他用户安装 LeafMem 后，按本目录的模板在宿主里创建运维自动化任务。
> **必选**：`weekly-maintenance.md`（每周深度整理）+ `daily-sentinel.md`（每日只读健康哨兵，异常才提醒）。
> 两者构成稳态运维闭环：每周整理负责记忆质量，每日哨兵负责系统健康（周中 MCP 掉线/数据库异常能当天发现）。
> 模板均为通用文本，不含任何个人路径/密钥；由宿主按提示词创建对应的定时自动化。

## 使用方式

1. 让宿主读取本目录的模板文件。
2. 宿主按模板内容创建一个定时自动化任务（WorkBuddy/昆仑小智均支持自动化）。
3. 任务首次运行时会自动召回 `leafmem-maintenance` 技能并按其 SOP 执行。

## 模板清单

| 文件 | 节奏 | 作用 | 必选 |
|------|------|------|------|
| `weekly-maintenance.md` | 每周一 04:00 | 深度整理（存档→去重→整合→蒸馏→镜像→报告） | ✅ 必选 |
| `daily-sentinel.md` | 每日 10:00 | 只读健康哨兵（MCP/存储/canary/误删检测，异常才提醒） | ✅ 必选 |
